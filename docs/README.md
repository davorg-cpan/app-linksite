# App::LinkSite

App::LinkSite builds a self-hosted links page from a JSON file.

The [canonical user guide](https://github.com/davorg-cpan/app-linksite/blob/main/README.md)
covers installation, configuration, images, sections, Docker, GitHub Pages,
and troubleshooting. See a [live example](https://links.davecross.co.uk/).

For work on the generator itself, read the
[development guide](https://github.com/davorg-cpan/app-linksite/blob/main/CONTRIBUTING.md)
and
[coding-agent guidance](https://github.com/davorg-cpan/app-linksite/blob/main/AGENTS.md).

The active documentation deployment publishes the root README. This file
keeps the older Jekyll entry point useful without duplicating that guide.
